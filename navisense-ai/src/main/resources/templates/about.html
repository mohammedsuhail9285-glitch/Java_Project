About NaviSense AI

Intelligent Freight Forecasting Model for Optimized Vessel Chartering and Bulk Cargo Procurement from Overseas to East Coast of India.

Target Stakeholders & End-Users

  • Organization: Ministry of Steel, Government of India
  • Department: Steel Authority of India Limited (SAIL)
  • Primary End-Users: Logistics Directors, Procurement Heads, Chartering Officers
  • Import Commodities: Low-Vol Hard Coking Coal, PCI Coal, Thermal Coal, Limestone
  • Overseas Basins: Australia (Hay Point, Gladstone), USA, Mozambique, Russia, Indonesia
  • Discharge Hubs: Paradip, Visakhapatnam, Gangavaram, Dhamra, Gopalpur, Haldia

Enterprise Architectural Principles

  • 100% Offline Capable: Zero external paid API dependencies or commercial API keys.
  • Pure Java 21 Stack: No fragile external Python runtime bridges.
  • Mathematical Transparency: Deterministic ensemble forecasting with verifiable audit trails.
  • Digital Port Enforcements: Strict draft, beam, and LOA checks prevent berthing casualties.
  • Full Traceability: Every analysis is fingerprinted (NAV-26006-...) and logged in H2.
